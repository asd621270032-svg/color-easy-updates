# Color Easy 手動更新下載

此公開庫只存放 Color Easy 的 macOS Universal App 安裝 ZIP、版本說明及 SHA-256 校驗值；不包含應用程式原始碼、病例、患者照片、診斷資料或密鑰。

請到 [Releases](https://github.com/asd621270032-svg/color-easy-updates/releases) 選擇版本，下載完整 ZIP，退出舊版 App 後再手動安裝。App 內的「說明 → 下載更新（手動安裝）」只開啟此頁，不會自動下載或安裝。

目前套件未經 Apple 開發者簽署或公證；此下載方式不會解除 macOS Gatekeeper。安裝前請核對 Release 所列的 SHA-256。
